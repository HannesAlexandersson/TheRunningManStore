# The runningmans store
This is another school assignment for ITHS Cloud developer YH program. This part is an admin interface for the Runningmans store

## What is it?
Its an Avalonia applikation thats purely for educational purpuses. It's not intended for commercial uses and isnt connected to any real webcommerce currently in use. 

## How to use
You need to clone or fork the repo so you get an local version. 
Theyou need to install the dependencies. 

Thenyou can start the application with the CLI command: 
```bash
dotnet run
```
